# notebooks
Example notebooks for wavespectra

## New to Python?

- [Getting started with wavespectra on Windows](getting-started-windows.md) —
  from a blank Windows machine to a running Jupyter notebook with wavespectra
  installed, aimed at people coming from a MATLAB background.
- [hp01_quickstart.ipynb](hp01_quickstart.ipynb) — read spectra from file, run
  the Hanson & Phillips (2001) partitioning and evaluate the results.

## Tutorial

The [tutorial](tutorial) folder contains a notebook series covering data
structures, I/O, spectral statistics, plotting, partitioning and real-data
examples.
